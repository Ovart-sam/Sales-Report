# Sales-Report

### Project Overview 

 The dashboard provides a detailed analysis of monthly fluctuations and individual performance metrics for the sales team, helping monitor progress toward goal. It also tracks sales by country, with *Australia* having the most sales activity. 

 ### Data Source

 Sales data: The primary dataset used for this analysis 'https://github.com/Ovart-sam/Sales-Report/blob/4e08153ead4c760b332adce8b0776cb0cb0d610f/ac-sample-data.xlsx' file, containing detailed information about each sales made by the compamy 

 ### Tools
 - Microsoft Excel - Data cleaning
 - PowerBI - creating visualization report

### Data Cleaning/Preparation
In the initial data preparation phase, i performed the following task:
1. Data loading and inspection

3. Data cleaning and formatting

### Exploratary Data Analysis
EDA involved exploring the sales data to answer key questions , such as:

- what is the overall sales trend?
- Which product are top sellers?
- What are the peak sales period?

 ### Result/Fiding

  The analysis result is summerized as follows:
- Total Sales: 34M  
- Units Sold This Month: 2.53 million  
- Month-over-Month Sales Decrease: 10.8
- Total Boxes Sold: 2 million  
- Total Shipments: 6,000  
- Total Costs:14M  
- Total Profit: 21M (60.3)
- Top Salesperson: Beverie Moffet with 1.35M in sales and $723K profit  
- Top Country for Sales: Australia  
- Sales Fluctuations: Sales peaked in mid-2023 and varied by month  
- Sales Performance: Dashboard tracks individual performance, sales goals, and profit margins
